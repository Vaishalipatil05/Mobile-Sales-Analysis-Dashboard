# Mobile-Sales-Analysis-Dashboard
###  **Mobile Sales Dashboard – Power BI Project**

####  **Project Overview**
This Power BI dashboard analyzes **mobile sales performance** to help identify **top-selling brands**, sales trends, and key performance indicators (KPIs).  
The project provides clear insights into sales distribution, product performance, and regional comparisons for better business decisions.

---

####  **Objective**
- To analyze overall mobile sales performance.  
- To identify **top-performing brands and models**.  
- To monitor sales trends and total revenue over time.  
- To make data-driven decisions through visual insights.

---

####  **Project Files**
- `Mobile_Sales_Dashboard.pbix` → Power BI dashboard file  
- `Mobile_Sales_Data.xlsx` → Raw dataset used for visualization  

---

####  **Tools & Technologies**
- **Microsoft Power BI** – for data visualization  
- **Microsoft Excel** – for dataset preparation  

---

####  **Key Insights**
- Visualizes sales performance using charts and KPIs.  
- Highlights **top-selling mobile brands** and categories.  
- Shows total sales, revenue trends, and region-wise comparison.  
- Easy to understand and helps track growth effectively.

---

####  **How to Use**
1. Download the `.pbix` and `.xlsx` files.  
2. Open the `.pbix` file in **Power BI Desktop**.  
3. Connect it to the provided dataset if needed.  
4. Explore the visuals and interact with filters for insights.
